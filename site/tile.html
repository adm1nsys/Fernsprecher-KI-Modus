Tile modules

Each frame runs the current state's module, then scene, which draws everything. A state module just sets a few values: o.dotColor (o.grey, o.brandColor, o.yellow or any CSS colour), o.dotAlpha, o.pulse (orb size change), o.particles, o.corner (small orb top left with subtitles), o.darken. Useful inputs: o.t (seconds), o.level (voice 0…1). Positions and sizes live in scene. Picking a state tab also shows that state; edits apply live and are kept in this browser.

Export saves fernsprecher-tile.json to Downloads. Then tell Claude, it runs python3 Tile/sync.py ~/Downloads/fernsprecher-tile.json and the call gets your tile.
